# 現実側ウィンドウ：C++の設計

VR側とは別に、現実側に情報を提示するための仕組みとして、プロジェクトには `URealSideWindowSubsystem` が含まれます。以下はC++ソースを読んで確認した処理です。ゲーム中の呼び出し条件と実機での表示は未確認です。

1. `OpenRealSideWindow` は表示する `UUserWidget` のクラスを引数で受け取ります。クラスが未指定の場合は警告を出して終了します。
2. すでにウィンドウが存在する場合は新たに作らず、既存のウィンドウを前面に出します。
3. Widgetを生成し、ディスプレイ情報からプライマリ以外のモニターを探します。見つかると、その作業領域を初期位置とサイズに使います。見つからない場合は位置 `(100, 100)`、サイズ `1280 × 720` を使います。
4. Slateの `SWindow` にWidgetを配置し、位置とサイズを設定して表示します。
5. ウィンドウが閉じたときは参照を解除し、Subsystemの終了時には残ったウィンドウの破棄を要求します。

`OpenRealSideWindow` は `BlueprintCallable` で公開されており、BlueprintからWidgetクラスを指定して呼び出せます。ただし、実際にどのBlueprintが呼び出すかは確認できていません。ウィンドウ生成にはSlateとモニター情報のAPIを使っていますが、C++を選択した当初の理由は確認できていません。

プロジェクトのモジュール設定には `Core`、`CoreUObject`、`Engine`、`InputCore`、`UMG`、`Slate`、`SlateCore`、`ApplicationCore` が指定されています。ソース単体は独立してビルドできず、Unreal Engine、プロジェクトのモジュール設定、Widgetなどが必要です。
