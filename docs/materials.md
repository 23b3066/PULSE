# 資料の追加・公開前確認

## 撮影・収集候補

| 素材 | 撮影・準備の方法 | 伝えたいこと |
| --- | --- | --- |
| VR側のゲーム画面 | 実機またはVR Previewで探索中の視点を撮影。UIや個人情報の映り込みを確認 | 世界観とプレイ視点 |
| 現実側の画面 | 実行中のモニターUIを撮影。実機の画面であることを明記 | VR側とは異なる情報と支援手段 |
| タイル・センサー | ギミックの前後とセンサー操作を同じ条件で記録 | 現実側の操作とゲーム内の変化 |
| 物理デバイス | 機器の全景と操作している手元を撮影 | 実際に使用する装置と操作方法 |
| Blueprint | 自分の担当箇所をエディターで拡大して撮影。全体と主要ノードを分ける | 実装上の工夫 |
| プレイ動画 | 両者の視点と実機操作が分かる短い映像を撮影・編集し、外部サービスへ掲載 | 協力の流れとゲームの雰囲気 |

動画・写真に映る人物は本人の掲載許可を得てください。

## 制作情報の確認

- 開発期間、チーム人数、制作目的、担当者ごとの役割
- 自分が担当したBlueprint、C++、デバイス、UI、企画の範囲
- 外部アセットと自作部分の区別、必要なクレジット
- 展示、受賞、公開歴など、根拠を示せる制作実績
- 使用したVR機器、センサー、通信方式、実機で動作した機能
- 心拍数とゲーム演出の関係、各スキルの効果、操作と進行の流れ

## 公開前の確認

- スクリーンショット内の外部アセット、BGM、人物、名前、アカウント情報について公開権限を確認する。
- Blueprintやコードは権利者と共同制作者の許可を得て、自分の担当範囲と説明を添える。
- トークン、ポート名、個人情報、非公開の画面や資料を含めない。
- 実装、実機検証、企画案の区別を保ち、古い設計案を完成済みとして示さない。
- 動画は大容量ファイルをGitHubに直接置かず、公開可能な外部リンクを掲載する。
